# 锁分析

锁分析功能支持对 MySQL 实例进行死锁分析、元数据锁分析和事务锁分析，帮助快速定位和诊断锁相关问题，减少 DBA 排查工作量。

## 注意事项

* MySQL 版本需要 ≥ 5.7。
* 死锁分析无需额外参数配置。
* 元数据锁分析和事务锁分析需要实例开启 `performance_schema`，开启该参数需要重启数据库。
* 元数据锁分析和事务锁分析还需要配置 `performance-schema-instrument` 中 `wait/lock/table/sql/handler` 和 `wait/lock/metadata/sql/mdl` 为启用状态，或设置 `performance-schema-instrument='wait/lock/%=ON'`。
* 创建分析后，仅可在当前详情页执行 Kill 操作；保存为快照后查看历史记录时，不再支持 Kill 操作。
* 历史快照保留 30 天。

## 进入锁分析

在"实例管理"页面，点击目标实例名称，进入实例详情页面后点击"锁分析"，即可进入锁分析功能页面。

## 死锁分析

### 创建死锁分析

在死锁分析页面，点击"创建分析"，系统将采集实例当前的 InnoDB 死锁信息并生成一条分析记录。

> **说明：** 该操作为同步操作，无需选择时间范围。点击创建后，系统立即采集当前时刻的锁信息。

创建分析后，可将结果保存为快照，保存后可在历史记录中查询。


![image](/images/dead-lock-create.png)

### 查询死锁分析记录

死锁分析记录列表展示已保存的历史快照，支持按时间范围筛选和分页查询。

* **时间范围**：支持选择近一天、近 3 天、近一周，自定义时间范围不能跨越 7 天。
* **列表信息**：
  * 诊断时间：分析触发的时间。
  * 锁发生时间：死锁发生的时间。
  * 操作：点击"详情"可查看死锁详情。


![image](/images/dead-lock-history-list.png)

### 死锁详情

点击快照列表中的"详情"，进入死锁详情页面，包含"列表"和"日志"两个视图。

**列表视图**

以表格形式展示解析后的死锁事务信息，包含两条事务记录：一条为正在执行的事务（executed），一条为被回滚的事务（rollback）。

**日志视图**

展示 InnoDB 死锁的原始检测日志文本（SHOW ENGINE INNODB STATUS 中的 LATEST DETECTED DEADLOCK 部分）。

![image](/images/dead-lock-history-detail.png)

## 元数据锁分析

### 创建元数据锁分析

在元数据锁分析页面，点击"创建分析"，系统将采集实例当前的元数据锁信息并生成一条分析记录。

> **说明：** 创建分析前请确认实例已开启 `performance_schema`。

![image](/images/meta-lock-create.png)

### 查询元数据锁分析记录

元数据锁分析记录列表展示已保存的历史快照，支持按时间范围筛选和分页查询。

* **时间范围**：支持选择近一天、近 3 天、近一周，自定义时间范围不能跨越 7 天。
* **列表信息**：
  * 诊断时间：分析触发的时间。
  * 操作：点击"详情"可查看元数据锁详情。

### 元数据锁详情

创建分析后立即进入详情页面，可通过锁状态筛选和表名搜索定位关键信息。

在详情页中，可对持有锁的会话执行 Kill 操作，终止该会话以释放锁。该功能复用会话管理的 Kill 能力。保存为快照后，查看历史记录时不再支持 Kill 操作。

## 事务锁分析

### 创建事务锁分析

在事务锁分析页面，点击"创建分析"，系统将采集实例当前的 InnoDB 事务锁等待信息并生成一条分析记录。

> **说明：** 创建分析前请确认实例已开启 `performance_schema`。

### 查询事务锁分析记录

事务锁分析记录列表展示已保存的历史快照，支持按时间范围筛选和分页查询。

* **时间范围**：支持选择近一天、近 3 天、近一周，自定义时间范围不能跨越 7 天。
* **列表信息**：
  * 诊断时间：分析触发的时间。
  * 操作：点击"详情"可查看事务锁详情。

### 事务锁详情

创建分析后立即进入详情页面，包含"阻塞关系图"和"会话列表"两个视图。

**阻塞关系图**

以有向图形式展示会话之间的阻塞关系。每个节点代表一个会话，节点上显示会话 ID，箭头方向表示阻塞关系（A → B 表示会话 A 阻塞了会话 B）。点击节点可查看该会话的详细信息。

![image](/images/translation.png)


**Kill 会话**

在详情页中，可对持有锁的会话执行 Kill 操作，终止该会话以解除阻塞。该功能复用会话管理的 Kill 能力。保存为快照后，查看历史记录时不再支持 Kill 操作。
