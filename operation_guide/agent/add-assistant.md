# 新增UDAC Agent助手

![配置助手](/udac/images/agent-add-assistant-step1.png)

1. 选择纳管数据库类型。
2. 选择数据库实例（数量不超过规格上限）。需要先在UDAC实例管理tab中将对应实例导入进去，具体操作步骤见https://docs.ucloud.cn/udac/operation_guide/mysql/import-instance。

![配置助手-纳管数据库](/udac/images/agent-add-assistant-step2.png)

3. 填写Agent名称。
4. 配置是否开启运维报告。

![配置助手-管理](/udac/images/agent-add-assistant-step3.png)
