# 技能列表

| 场景         | 说明                                                         | 诊断所需参数                           |
| ------------ | ------------------------------------------------------------ | -------------------------------------- |
| CPU 诊断     | 诊断数据库实例 CPU 相关问题，区分正常业务增长和性能异常      | instance_id，时间范围                  |
| CPU 实时诊断 | 实时诊断当前时刻 CPU 使用率异常原因，通过即时拉取多维度数据快速定位根因 | instance_id                            |
| 内存诊断     | 诊断数据库实例内存使用率异常，通过缓冲池命中率、临时表、连接数等多维度分析定位根因 | instance_id，时间范围                  |
| 慢日志分析   | 基于慢日志统计数据分析问题 SQL，识别多种类型的问题 SQL 并提供优化建议 | instance_id，时间范围，返回前 N 条结果 |
| 死锁分析     | 分析数据库实例最近一次死锁，还原锁等待链，定位涉及事务和 SQL，给出规避建议 | instance_id                            |
| 会话诊断     | 实时查询 MySQL 实例会话列表，识别异常会话（长时间运行、锁等待、空闲事务、大事务、连接数异常），输出 Kill 建议 | instance_id                            |
| IO 诊断      | 诊断数据库实例磁盘 IO 相关问题                               | instance_id，时间范围                  |
| 空间诊断     | 分析数据库实例磁盘空间使用概况，识别存储风险，列出待优化大表和碎片表 | instance_id                            |
