# 计费说明

**中国内地**

| 规格项         | 基础版                                         |
| -------------- | ---------------------------------------------- |
| Agent助手数量  | 1                                              |
| 纳管实例数上限 | 10                                             |
| 支持DB类型     | MySQL                                          |
| 地域可用区     | 中国内地通用                                   |
| 字符限额       | Agent服务49元/月 + 按字符数后付费0.0005元/字符 |
| 并发数         | 1                                              |

* 开通Agent服务，收取49元/月的预付费。
* 如提前退订，月费按当月已使用天数等比例扣减后退还剩余部分。如月费49元，当月30天，已使用15天后退订，退还24.5元。退订后数据不保留。
* UDAC Agent产品中的字符数，包含提问与回答，以及运维日报的字符数。字符包含汉字、英文、标点符号、换行符等特殊字符，如【当前数据库实例udbha-1234567没有异常。】共25个字符。
* UDAC Agent不直接使用token计量，对用户侧所见即所得。用户查询实例是否异常时，Agent会从CPU/IO/QPS/TPS/内存等多个指标、慢SQL清单、锁分析结果等多角度查询并判断，消耗大量token。如有异常，回答可能上千字符；如无异常，回答可能仅十几个字符。为让客户直观感受用量，直接按问答字符数计费。一般一次诊断消耗3000-5000字符，一次运维日报约5000字符。您可在Agent详情页查询每次对话或报告的字符用量。

> 企业版即将上线，支持纳管更多实例和更高并发。
